# Elorin RSPS main site - UI kit

One screen: the pre-launch homepage at elorin.org, so documentation pages can be checked
against the chrome they extend.

| File | Surface |
| --- | --- |
| `index.html` | Header (split lockup, Account / Logout), homepage, footer |
| `HomeScreen.jsx` | Coming-soon pill, countdown, logo, hero, intro copy, CTA pair, three feature cards |

**Source caveat.** Only a screenshot of the homepage was supplied - no site code and no
Figma file. Spacing, sizes and the countdown treatment are measured off that screenshot
and are approximations. The gold values are exact (given in the brief as the live
gradient definitions); navy and grey values are sampled.

**Deliberately blank.** The feature cards' concept art is a placeholder panel with the
brand diamond - the real artwork was not supplied and is not reconstructed here. The
footer composition is inferred: the screenshot cut off before it. Account, vote and
download pages are not recreated.
